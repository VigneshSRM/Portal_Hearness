Connecting to your Redmine

  1. Enable the REST API in Redmine: Administration → Settings → API → Enable REST web service.
  2. Copy your key from My account → API access key (right-hand sidebar, "Show").
  3. Put these in the .env file next to config/ (create it with python harness.py init): 
    REDMINE_URL=https://redmine.your-company.com
REDMINE_API_KEY=your-40-character-api-key
  4. Check the connection: python harness.py check, then restart the dashboard.
